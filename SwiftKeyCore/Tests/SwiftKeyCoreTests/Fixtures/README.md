These are public, non-secret conformance fixtures, independently constructed
with Python's struct/hashlib/unicodedata and OpenSSL 3.6.3.

`canonical-v1.json` contains fixed canonical bytes and SHA-256 hashes for a
challenge, delegation and workload. Its encoding does not call SwiftKeyCore.
Inputs are recorded directly in ProtocolTests.swift. The public P-256 point is
the standard generator (test scalar 1), not a production identity.

`openssl-message.bin` is the fixed canonical workload. `openssl-signature.der`
was generated by OpenSSL `dgst -sha256 -sign`, using that public test scalar in
an RFC 5915 private-key container. The private container was created only in a
temporary directory and removed afterward. The stored public PEM and X9.63
bytes allow independent verification:

```sh
openssl dgst -sha256 -verify openssl-public.pem \
  -signature openssl-signature.der openssl-message.bin
```

Expected output: `Verified OK`. Tests also reject a changed message and a
signature with trailing bytes, and confirm prehashed verification hashes only
once. These fixtures never satisfy hardware attestation or root enrollment.
