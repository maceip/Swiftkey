# Bundled fonts

These fonts come from the existing SwiftKey design system. The Host Grotesk copies
retain their glyphs and outlines, with corrected family/style/PostScript name
records and weight metadata for each static weight so iOS registers them separately.
JetBrains Mono is unchanged. The Xcode project bundles both original OFL licenses
from `SwiftKeyDesign/licenses/` alongside the fonts.

Names registered by the app: `HostGrotesk-Regular`, `HostGrotesk-Medium`,
`HostGrotesk-SemiBold`, `HostGrotesk-Bold`, and `JetBrainsMono-Regular`.
